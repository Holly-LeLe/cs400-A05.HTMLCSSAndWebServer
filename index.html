Binary Search Tree

What is a Binary Search Tree?

A binary search tree is a data structure that stores values in a sorted way. Values smaller than a node go to the left, and values larger than a node go to the right.

Important Features

  • Each node has at most two children.
  • Smaller values are stored on the left side.
  • Larger values are stored on the right side.

Binary search trees are useful for searching sorted data.
